# Janus Tsen

A static personal website: one long homepage plus a Bookshelf page. Deploy `dist/`; no build or production dependencies. This redesign is for preview review; nothing goes live until Janus approves it.

Cloudflare Pages uses `dist/404.html` for unknown URLs, with a link home. `dist/robots.txt` allows all crawlers. Every page links the stylesheet, scripts and drawings with a `?v=<content hash>` query, so a deploy that changes one gives returning visitors a new URL instead of a cached copy (Cloudflare serves them with a 4-hour browser cache regardless of `dist/_headers`). After editing any of those files, run `npm run stamp` and commit the updated HTML; `npm run lint` (and CI) fails while a stamp is stale. The homepage and Bookshelf declare their canonical URLs and Open Graph/Twitter card metadata.

## Installation

`npm ci` installs the one dev dependency (`playwright-core`, used only by the verification script). The site itself needs no install.

## Usage

Preview: `python3 -u -m http.server 63027 --bind 127.0.0.1 --directory dist`.

`npm test` drives both pages in a real browser; `npm run lint` checks JavaScript syntax for both site scripts and the verification script, and that asset version stamps are current.

For verification setup and detailed checks, follow [.agents/skills/verify-janus-site/SKILL.md](.agents/skills/verify-janus-site/SKILL.md).

## Design and sources

The look follows alexanderobenauer.com: a single column, the name in condensed capitals with inline contact links, a serif intro, vertical section labels (About, Building, Experience, Strategy, Values, Tech & AI, Design, Books, Other interests), italic serif entry titles with short descriptions, a full-width line drawing beside each section, simple rules between sections, and a quiet centered footer. The drawings are pure-stroke SVGs in `dist/assets/drawings/` (800×1000, `currentColor` ink). There is exactly one per section (Building, Experience, Strategy, Values, Tech & AI, Design, Books); About is text only and Other interests has none. Each is pinned only while its section's text is beside it and is fully drawn before it releases, and the strokes add depth with thickness and hatched shadows. Janus's own line portrait, embedded unchanged in `portrait.svg`, is the masthead mark. It draws itself in once on load (about 2.4 s, no scroll needed): the face shows at once, then the hair and suit draw in. Until `site.js` swaps in the drawing copy, the static image waits hidden (the head script sets `mark-wait`), so it never shows whole and then restarts; it shows anyway after 4 seconds, and if it already showed, the drawing skips the draw-in. With reduced motion or no JavaScript it shows complete. The repo's `wrangler.jsonc` only exists so the connected Cloudflare Workers project named `personal-website` can build; Pages ignores it. `dist/assets/janus-tsen.jpeg` is not shown on the page; it is the link-preview (Open Graph) image. No profile photo appears on the page. The masthead mark is the line portrait at 200 px wide (160 px at 1100px and below, 112 px on phones), followed by a thin vertical rule as tall as the portrait and then the name, contact links and section links, all set left against the rule (on phones of 560px and below the portrait sits above and the rule turns horizontal). The header bar shows only the name; the first-visit intro shows the portrait at 160 px. No text, images, logo, or code were copied from that site. `/building/`, `/experience/`, and `/about/` redirect to their homepage sections. There is no dark theme.

Entries gently fade and rise as they scroll into view; disclosures fade in, and section links scroll smoothly. Anything on screen at load shows at once. On screens wider than 760px, each section label and drawing pins below the header bar while its entries scroll, then releases. The drawing's strokes draw in with scroll while the section is on screen: from the moment its top reaches 85% of the viewport to about two-thirds of the way through the section. On phones the drawing sits after the section's first entry and scrubs as it crosses the screen. A thin header bar (name, section links with the current one marked) replaces the masthead once it scrolls away. Reduced motion disables scroll, disclosure and draw-in animations, shows drawings fully drawn and switches the bar without animation. Without JavaScript, content and drawings appear static and native disclosures still work. Held-back drafts remain hidden in both modes.

The homepage opens with a short intro on a visitor's first load in a browser tab. Only the line portrait and "Hey, I'm Janus!" show, centered, with no scroll cue: the portrait draws itself in, in step with the masthead copy it later lands on, and the letters rise in. The first scroll, swipe, key or tap, or three seconds without one, whips both into the header (the greeting becomes the name) while the page fades in. It plays once per tab session (`sessionStorage`). Reloads, deep links such as `/#building`, blocked storage and no JavaScript go straight to the page. Reduced motion shows the portrait (fully drawn) and greeting still, then fades to the page. The inline script in the head of `dist/index.html` decides whether it plays; the intro itself is at the end of `dist/site.js`. If that script has not started the intro within 4 seconds, the head script cancels it and the page shows normally (a CSS fallback also reveals it after 8 seconds).

Four personal entries (V1, V3, V5, B1) are held back: they keep `data-draft="ID"` and `hidden`, so they never show. To publish one, remove both attributes; to cut it, delete the element. Update the list in `verify.mjs` either way.

The homepage offers Email and LinkedIn contact links, uses the line portrait for the masthead mark and links to the verified GitHub profile at `github.com/janustsen`. X links to the user-provided profile at `x.com/janustsen`.

Copy follows the user's professional positioning, with public evidence links beside the relevant work. External links use plain underlined text without diagonal arrow glyphs; the Bookshelf back link retains its left arrow. Building links to Verdnt Group’s current site and identifies Trus as retired. Crimson Pro, Inter, and Unica One are self-hosted under the SIL Open Font License; see `dist/assets/fonts/LICENSES.txt`.

No private source documents, client datasets, credentials, or contact submissions are packaged.

Bookshelf offers 20 sourced philosophy/business suggestions, tier drag-and-drop with a keyboard alternative (select a book and press S, A, B or C), and filtering. Book entries carry no tier or reading-status menus. Initial rankings were suggested from inferred interests; the public interface uses simple S/A/B/C labels. Changes persist only in the visitor’s browser; Reset restores the suggestions. Multiple book notes can stay open for comparison. Native book details remain available without JavaScript; moving books, filtering, and reset require JavaScript. Search, topic, and reset controls reserve their space before scripts load and are hidden when JavaScript is disabled. Search and topic selections made during loading apply when the script initializes.
