# Janus Tsen

A static personal website: one long homepage. Deploy `dist/`; no build or production dependencies. This redesign is for preview review; nothing goes live until Janus approves it.

Cloudflare Pages uses `dist/404.html` for unknown URLs, with a link home. `dist/robots.txt` allows all crawlers. Every page links the stylesheet, scripts and drawings with a `?v=<content hash>` query, so a deploy that changes one gives returning visitors a new URL instead of a cached copy (Cloudflare serves them with a 4-hour browser cache regardless of `dist/_headers`). After editing any of those files, run `npm run stamp` and commit the updated HTML; `npm run lint` (and CI) fails while a stamp is stale. The homepage declares its canonical URLs and Open Graph/Twitter card metadata.

## Installation

`npm ci` installs the one dev dependency (`playwright-core`, used only by the verification script). The site itself needs no install.

## Usage

Preview: `python3 -u -m http.server 63027 --bind 127.0.0.1 --directory dist`.

`npm test` drives both pages in a real browser; `npm run lint` checks JavaScript syntax for both site scripts and the verification script, and that asset version stamps are current.

For verification setup and detailed checks, follow [.agents/skills/verify-janus-site/SKILL.md](.agents/skills/verify-janus-site/SKILL.md).

## Design and sources

The look follows alexanderobenauer.com: a single column, the name in spaced serif capitals with inline contact links, a serif intro, vertical section labels (About, Building, Experience, Values, Books, Other interests), italic serif entry titles with short descriptions, a full-width line drawing beside the drawn sections, simple rules between sections, and a quiet centered footer. The drawings are pure-stroke SVGs in `dist/assets/drawings/` (800×1000, `currentColor` ink). There is exactly one per drawn section (Building, Experience, Values); About is text only, Books has its bookcase instead and Other interests has none. Each is pinned only while its section's text is beside it and is fully drawn before it releases, and the strokes add depth with thickness and hatched shadows. Janus's own line portrait, embedded unchanged in `portrait.svg`, is the masthead mark. It draws itself in once on load (about 2.4 s, no scroll needed): every stroke draws at the same time, and the face (a filled shape in the drawing's mask) fades in alongside. Until `site.js` swaps in the drawing copy, the static image waits hidden (the head script sets `mark-wait`), so it never shows whole and then restarts; it shows anyway after 4 seconds, and if it already showed, the drawing skips the draw-in. With reduced motion or no JavaScript it shows complete. Before a section drawing draws in, a faint copy of it (15% ink) shows in its place, so the column beside the text is never empty, Building's included at the top of the page. The repo's `wrangler.jsonc` only exists so the connected Cloudflare Workers project named `personal-website` can build; Pages ignores it. `dist/assets/janus-tsen.jpeg` is not shown on the page; it is the link-preview (Open Graph) image. No profile photo appears on the page. The masthead is the line portrait on the left at 200 px wide (160 px at 1100px and below), a thin vertical rule as tall as the row, then the name, contact links and section links on the right; the whole group sits centered on the page. On phones of 560px and below the portrait (120 px) stacks above the text, all centered, with a horizontal rule between them. The header bar shows only the name; the first-visit intro shows the portrait at 160 px. No text, images, logo, or code were copied from that site. `/building/`, `/experience/`, and `/about/` redirect to their homepage sections. There is no dark theme.

Every section drawing and the portrait hide small easter eggs (`dist/eggs.js`): parts to drag (they ease back, or stay put where that makes sense), tap or hover, and one secret each after several taps. Only invisible hit areas over those parts take the pointer, so nothing else in a drawing gets in the way, and they move with smooth ease curves, never a bounce. On touch, sideways drags hold the page while vertical swipes still scroll. Reduced motion keeps the eggs but swaps movement for appearing and disappearing. Without JavaScript the drawings are plain images. The full list is in `.agents/skills/verify-janus-site/features/eggs.md`.

Values lists four values (Optimization, Human relations, Multiplying throughput, Candor), each grounded in Janus's own records. Books is a drawn bookcase: a Read shelf (the books Janus has read) and a Suggested reads shelf (20 suggested reads). The shelf looks lived in: on each of its three shelves a few books lie flat in a stack, one or two lean on a neighbour or the bookend, and one stands face-out; a cat sleeps on top, and a plant, a mug, a pair of glasses, an open book, a bookend and a spider sit among the books. Each spine is a button that opens a native popover (`popovertarget`, so it works without JavaScript) with a framed cover carrying the title, author and the book's own small line illustration, plus the book's note; Escape, a click outside or Close dismisses it. With motion, `dist/books.js` spins the book out of the shelf (a rotateY turn, then an ease-out flight into the preview, about 700 ms, played back on close) and the illustration draws itself in; reduced motion fades the preview and shows the illustration whole (the illustrations are inline in `dist/index.html`). Other interests is one drawn room, centered: a corner of Janus's room at golden hour in one perspective, lit from the window on the left. A hangboard over the door with a rope coil and a chalk bag (Climbing), a gi and black belt on a peg rail under a medal (Karate), sneakers kicked off by the door (Running), a sewing machine with a pair of jeans under the needle and a yarn basket beside the desk (Sewing), a dress form with a tape measure (Fashion), a clothes rack with a price-tagged jacket (Thrifting), a mirror with clippers, shears and a comb (Cutting hair) and Statesman mid-game on the rug (Board game design). The room is grey and the eight hobbies are dark ink; each is a button (in the room's 800×500 coordinates, so the pieces overlap like one drawing) that opens a native popover card with the hobby's text; only one card is open at a time and Escape or a click outside closes it. There are no dots: hover or keyboard focus lifts the object slightly, traces its outline and shows a lettered label on a thin leader line, and every outline traces once when the room first scrolls into view. Without hover (phones) the labels always show; hit areas are at least 44px. At 560px and below the room crops its empty left and top margins. Small toys hide in the drawings (`site.js`, end of file); none blocks a card, only a real drag cancels the click, all work with touch, and reduced motion keeps the state without the movement. Hobbies: drag the belt or the rope and they swing back; drag the sneaker and it slides back; the needle stitches (and the seam grows) and the clipper spins on hover or tap; the die rolls and a pawn hops a square; each tap on the yarn basket unrolls the yarn a little; the thrift price tag drops each visit ($3, $2, $1, free); the tape measure sways on hover; three visits to Climbing leave a chalk handprint on the door; the wall clock shows the visitor's time. Books (`books.js` and `site.js`): drag an upright spine and it swings back, or drag a leaning book upright and it eases back against its neighbour; nudge the bookend five times and a mouse peeks out; the mug steams; the glasses flip over; the open book turns a page; pull the spider down its thread and it climbs back; each cover's illustration has a part that moves on click (the sun sets, the gears turn, the bird leaves its cage...) and some reveal a hidden detail on the third click; an opened book keeps a bookmark ribbon; the cat on top flicks its tail when patted and wakes after three pats; the plant grows a leaf for each suggested read opened (up to three); a cover tilts toward the pointer, and three taps stamp it ex libris.

Entries gently fade and rise as they scroll into view; disclosures fade in, and section links scroll smoothly. Anything on screen at load shows at once. On screens wider than 760px, each section label and drawing pins below the header bar while its entries scroll, then releases. The drawing's strokes draw in with scroll while the section is on screen: from the moment its top reaches 85% of the viewport to about two-thirds of the way through the section. On phones the drawing sits after the section's first entry and scrubs as it crosses the screen. A thin header bar (name, section links with the current one marked) replaces the masthead once it scrolls away. Reduced motion disables scroll, disclosure and draw-in animations, shows drawings fully drawn and switches the bar without animation. Without JavaScript, content and drawings appear static and native disclosures still work. Held-back drafts remain hidden in both modes.

The homepage opens with a short intro on a visitor's first load in a browser tab. Only the line portrait and "Hey, I'm Janus!" show, centered, with no scroll cue: the portrait draws itself in, in step with the masthead copy it later lands on, and the letters rise in. The first scroll, swipe, key or tap, or three seconds without one, glides both smoothly into the header with an ease-out (no bounce or overshoot) (the greeting becomes the name) while the page fades in. It plays once per tab session (`sessionStorage`). Reloads, deep links such as `/#building`, blocked storage and no JavaScript go straight to the page. Reduced motion shows the portrait (fully drawn) and greeting still, then fades to the page. The inline script in the head of `dist/index.html` decides whether it plays; the intro itself is at the end of `dist/site.js`. If that script has not started the intro within 4 seconds, the head script cancels it and the page shows normally (a CSS fallback also reveals it after 8 seconds).

One personal entry (B1, the My Brilliant Friend spine on the Books shelf) is held back: it keeps `data-draft="B1"` and `hidden`, so it never shows. To publish it, remove both attributes; to cut it, delete the spine and its `#book-friend` popover. Update the list in `verify.mjs` either way.

The homepage offers Email, LinkedIn and Resume contact links (the resume is `dist/assets/janus-tsen-resume.pdf`), uses the line portrait for the masthead mark and links to the verified GitHub profile at `github.com/janustsen`. X links to the user-provided profile at `x.com/janustsen`.

Copy follows the user's professional positioning, with public evidence links beside the relevant work. External links use plain underlined text without diagonal arrow glyphs. Building identifies Trus as retired; the Verdnt Group link is removed for now. Body text, the name, contact links and section links (masthead and header bar) are set in Hedvig Letters Serif (Kanon Foundry), a single upright weight. It has no italic, so italic lines (entry titles, roles, book and publication titles) use Crimson Pro Italic, and nothing is bold; the bar marks the current section with an underline. The vertical section labels stay in Unica One. Hedvig Letters Serif, Crimson Pro Italic, Inter and Unica One are self-hosted under the SIL Open Font License; see `dist/assets/fonts/LICENSES.txt`.

No private source documents, client datasets, credentials, or contact submissions are packaged.
