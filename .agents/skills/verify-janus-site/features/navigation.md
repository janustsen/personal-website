# Navigation and contact

## Sub-features
Short homepage, separate Building / Experience / About routes, in-content home links, inner-page footer links, direct email and LinkedIn, external evidence links. There is no top bar.

## User path and drive
Open `/`, choose each named page link, confirm the route and heading, then follow `← Janus Tsen` home. `node verify.mjs` drives these paths in five browser contexts and checks keyboard focus. Inspect footer destinations without sending email. LinkedIn may require sign-in.
